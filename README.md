# Multi-Sensor-Lymphedema-Monitoring
Multi Sensor System for Early Monitoring of Cancer Related Lymphedema
Overview
An IoT-based wearable healthcare monitoring system developed using ESP32 and multiple biomedical sensors for early detection of cancer-related lymphedema. The system continuously monitors physiological changes such as temperature, pressure, strain, limb expansion, and motion to identify possible swelling conditions.

Sensor data is processed in real time and displayed on:
LCD display
Serial Monitor
Blynk IoT dashboard

The system classifies patient condition as:
NORMAL
SWELLING
and generates alert indications for early intervention.

Features:
Real-time physiological monitoring
ESP32-based wireless IoT system
Percentage-based swelling risk dashboard
Multi-sensor integration
LCD and Blynk monitoring
Early swelling detection
Alert indication system
Portable and low-cost design
